# Hardware catalog

This catalog is the previous hydrapool.org hardware table,
carried over as text. That page did not record when a row
was tested. Green rows there are **Tested** here. Every
other row was marked not tested.

The hash-power and efficiency columns are the figures that
table listed. They read as catalog numbers for the machine,
not as measurements published by Hydrapool.

The old page asked people to point hardware at
`stratum+tcp://test.hydrapool.org:3333`. This catalog does
not repeat that instruction. The Foundation's documented
public endpoint is the [hashrate-donation instance](/reference/public-instances).
