# Hardware

Hydrapool's current docs do not publish a hardware
compatibility list. The interface they document is
Stratum on the port in your config, 3333 in the v2.6.0
example. Whether a particular miner speaks that
interface is something you learn on an instance whose
payout rule you have already read.

The previous hydrapool.org page kept an undated table
of machines and nameplate figures, and it asked people
to point hashrate at `test.hydrapool.org`. That page
is legacy. It is not a current compatibility record,
and this site does not repeat the table or the
request.

The Foundation's public endpoint is the [donation
instance](/reference/public-instances). A block it
finds pays the Foundation, not the miner who
connected. To try a machine, use a pool you run.
